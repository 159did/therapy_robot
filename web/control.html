Therapy Robot Control

理疗机器人控制界面

主工作区集中显示穴位识别、三维仿真、末端实时位姿、增量点动和自动按摩；工程参数可通过“显示高级调试”展开。

顶部控制区始终可见 连接、使能、停止和下电已集中到页面最上方

三组电机目标位置

输入 MF9025V2 native 原始位置，单位统一为 0.01°/LSB；GUI 可按轴显示换算值。

物理量目标位置

K0 使用 mm；K1-K4 使用 deg。点击发送时会按当前轴映射自动换算成 native，并同步回上面的 native 输入框。

相机模拟输入

模拟未来 RGB-D 相机输出的穴位点坐标与皮肤法线姿态，点击换算后得到机器人基坐标系下的绝对末端目标。

相机到基座标定

先用外参近似仿真相机坐标到机器人基坐标的转换：p_base = R_calib · p_camera + t_calib。默认值已包含相机底面中心相对末端底面中心偏移 Y=-217mm、Z=+145.2mm。

相对零位目标

输入相对当前零位的偏移量，点击换算后自动填充右侧绝对末端目标。零位参考可后续按实际标定调整。

绝对末端目标

写入 control.endpoint_target，后续由 main_control 做逆解。

X/Y/Z 定义在按摩头工具最末端的 tip 点，不是圆柱底面或腕点。

IK 采用真实结构：K1-K2=580mm，K3-K4=229mm，K4刚性末端组件=119mm，末端下探=153.1mm；橙色末端长方体、K4轴电机和末端圆柱随K4一起旋转。

单轴匀速：等待启动；使用“立即停止”结束运动

匀速模式会让所选轴朝对应软限位持续运动；K0 使用配置文件中的原有速度，K1～K4 继续使用原有速度。必须由操作员观察实体并手动点击“立即停止”，到达软限位也会自动结束。

选择 K0 时步长会切换为 5/10/20/50/100mm，默认 20mm；旋转关节最大 10°。K0 是重力轴，必须先确认可靠支撑和急停可用。

故障自救：恢复点动

仅用于碰撞或软限位停止后脱离当前位置。先点击“全部下电”，再点击顶部“进入限位/碰撞恢复模式”，然后重新使能电机。

恢复时只允许单轴小步：K0最多每次5 mm且只允许向上；K1～K4最多每次2°。末端增量、目标位置和自动序列保持锁定。

这是受限的碰撞路径恢复，不是关闭碰撞检测；目标姿态仍必须离开末端和机箱碰撞边界。
