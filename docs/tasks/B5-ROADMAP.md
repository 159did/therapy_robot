# B5 实验版路线图（面向毕业课题）

基线：`30a91416e54cb6541ab1f3e206f4aa2e33a667c2`

目标不是做量产产品，而是完成一个能用于论文和答辩演示的实验闭环：

```text
机械臂安全启动
-> 低速移动到拍摄位置
-> 相机拍照
-> 识别/读取穴位
-> 规划末端位置
-> 在假人或模型上完成非接触演示
```

## 只保留 4 个大任务

| 阶段 | 内容 | 结果 |
|---|---|---|
| H1 | 只读确认机械臂和 K0 状态 | 知道机械臂当前在哪里，确认可以开始低速测试 |
| M1/M2 | 低速移动和左右拍摄路线 | 机械臂能到达左/右拍摄位置并安全返回 |
| VISION | 相机和穴位识别 | 能从照片得到穴位坐标，并转换成末端目标 |
| DEMO | 假人/模型非接触演示 | 完成“移动—拍照—识别—规划—撤离”闭环 |

## 实验项目的最低安全要求

只保留三条硬规则：

1. 第一次实体测试必须低速、短距离，并且旁边有人能立即断电/急停。
2. 先在假人或模型上做非接触演示，不直接做真人接触。
3. 任何实体测试前，先确认当前设备、串口和启动脚本，避免连错设备。

其余产品级审计、复杂授权链和多层报告不作为毕业课题阻塞项。

## 时间估计

在设备和人员可用的情况下：

- H1：半天到 1 天。
- M1/M2：1～3 天。
- VISION：3～7 天，主要取决于外参和识别效果。
- DEMO：2～5 天。

合计目标：约 1～2 周完成可演示的实验闭环；如果标定反复，按实际情况顺延。
