# B5-H1：第一次实体只读检查（简化版）

基线：`30a91416e54cb6541ab1f3e206f4aa2e33a667c2`

目标：用最短时间确认机械臂和 K0 的当前状态，为低速移动做准备。H1 只读，不修改参数，不做回零，不让电机运动。

## 只做 3 件事

### 1. 现场确认

确认设备、串口、操作者和急停方式。先看当前状态，不发送运动指令。

### 2. 读取并记录

记录以下内容即可：

- K0 当前高度/位置；
- K0 软限位；
- 抱闸状态；
- 反馈是否稳定；
- 当前软件提交号和时间。

### 3. 做决定

只有两种结果：

- `PASS`：状态清楚、反馈稳定，可以安排 M1 低速小距离测试。
- `BLOCKED`：状态不清楚或反馈异常，先修复，不进入运动测试。

## H1 现场最低停止条件

看到位置不稳定、抱闸异常、反馈丢失、设备不确定或急停不可用，就停止，不继续操作。

## 交付物

只需要保存一份现场记录和一份结论：

```text
H1-record.json
H1-result.md
```

不再要求为 H1 单独维护多套复杂审计包。原有 `B5-H1-APPLICATION.md` 和 `B5-H1-RECORD.md` 仍作为可选模板保留。
