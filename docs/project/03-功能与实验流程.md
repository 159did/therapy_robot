# 功能与实验流程

## 软件闭环

1. 离线图片进入 scripts/offline_vision_pipeline.py。
2. 识别背部/目标区域，输出穴位图像坐标、置信度和输入哈希。
3. 有深度时生成相机坐标；没有正式外参时只输出 candidate 坐标，保持 formal_use_allowed=false、promotion_locked=true。
4. B5 路线工具生成左右仿真路线，B6 末端契约校验单位、坐标系、非接触偏移、边界和权限。
5. B7/B8 API 和中央安全门阻止未授权实体控制；仿真结果不写实体 command/target。

## 离线实验

- 正常、缺图、尺寸错误、深度缺失、外参缺失/哈希不匹配、低置信度必须有确定性结果。
- B6/B8 故障包括急停、反馈丢失/过期、看门狗、软限位、碰撞、抱闸未知、授权过期；故障后不自动恢复。
- B8 VM 验收只使用 x86_64 VM 的新构建、隔离端口和隔离共享内存。
- 任何未来实体低速实验只能按 B8 单轴、单次、非接触、人工确认和逐步记录协议准备，不能由仿真结果自动升级。

## 实体实验闸门

GO 必须同时满足 H1 entity readonly pass、B8 safety gate、真实 Nano ARM64 证据、只读状态、急停、看门狗、反馈、软限位、碰撞、抱闸、具体动作批准、单一执行代理、操作者/急停负责人在场和现场无人。任一项不满足即 NO-GO。

当前 H1 实体只读已通过，但运动授权仍未通过，因此当前流程结论是 NO-GO / PREPARATION_ONLY。不允许接触人体、假人或其他物体，不允许自动序列、连续 jog、完整左右路线或穴位序列。
