# 项目架构与代码位置

## 分层

- src/core/main_core.cpp：共享状态核心、运行时初始化和心跳。
- src/web/main_web.cpp：只读状态、workflow/readiness/motion-plan API、仿真入口和控制安全门接入。
- src/control/main_control.cpp：endpoint/joint 目标转换、碰撞发布和安全门消费。
- src/motor/main_motor.cpp：电机状态、反馈、限位、抱闸、碰撞和硬件命令消费者；源码存在不代表已执行。
- src/sim/main_sim.cpp：仿真状态。
- src/common/shared_memory.cpp、shared_memory_defaults.cpp：共享内存对象和默认状态。
- include/therapy_robot/shared_memory.hpp：V3 ABI 数据结构。
- include/therapy_robot/control_safety_gate.hpp、src/common/control_safety_gate.cpp：B8 deny-by-default 安全门。
- scripts/offline_vision_pipeline.py：离线视觉图片到穴位/候选坐标流程。
- scripts/b6_ee_sim.py、scripts/b6/end_effector_offline_pipeline.py：末端契约和仿真。
- scripts/experiment_workflow.py、scripts/capture_d405.py：实验报告和显式相机入口；未授权时不得启动硬件。
- tools/h1_readonly_collector.cpp：H1 实体只读采集器；只读采集器本身不等于 H1 PASS。

## Shared Memory V3

SharedState.version=3。主要结构体：

- CommandState：command/target 序号和原生目标数组；正式实体目标必须受安全门约束。
- ControlState：心跳、endpoint target 和 collision state。
- SimulationState：hardware_mode、仿真末端位置。
- EntityControlSafetyState：execution_allowed、entity_action_authorized、h1_status、反馈、急停、限位、碰撞、看门狗、抱闸、请求和授权字段。
- MotorGroupState/MotorState：状态和目标字段，不是授权凭证。
- AxisMapEntry：轴映射和单位换算。

Shared Memory 名称由 shared_memory_name() 读取 THERAPY_ROBOT_SHM_NAME，非法名称在 shm_open 前拒绝。默认名为 /therapy_robot_shared_state。

## API 约定

只读 API 包括 /api/state、/api/readiness/attestation、/api/workflow/state、/api/workflow/self_check、左右 motion-plan preview、acupoints/latest 和 motion-test points。仿真 POST 只产生离线报告；实体 POST 先经过 classify_control_post、validate_control_body 和 evaluate_control_safety。

B8 安全门在 Web POST、main_control endpoint 消费和 main_motor 命令消费三处生效，默认：

H1_ENTITY_READONLY_PASS、execution_allowed=false、entity_action_authorized=false。
\n\n当前统一规则：H1_ENTITY_READONLY_PASS 只表示实体反馈读取和未动作审计通过；execution_allowed=false、entity_action_authorized=false、entity_motion_authorized=false 继续保持，任何实体运动仍需单独授权。\n
