# 分阶段机械臂工作流

## 当前实现

控制界面中的“开始分阶段流程”会建立左侧或右侧路线。随后点击“推进下一步”，系统一次只处理一个已定义路点，顺序固定为：

1. `SAFE_HIGH`：先到安全高位，末端高于机箱。
2. `SIDE_DEPLOY`：在高位向选择的左侧或右侧转出，大臂侧向展开。
3. `ARM_EXTENDED`：在机箱外侧分级下降，进入小臂伸出工作走廊。
4. `WORK_CORRIDOR`：沿预先检查的外侧工作点移动。
5. `RETURN_HIGH`：沿外侧原路抬升，再在高位回到中心。

每一步都重新使用逆运动学、软限位和碰撞路径检查。步骤不能跳过，下一步必须等待上一目标被控制进程确认。实体目标仍必须通过中央控制安全门；没有硬件授权、有效反馈或安全状态时，接口返回拒绝且不生成电机命令。

## 接口

```text
GET  /api/workflow/guided_plan?side=left|right
GET  /api/workflow/guided_state
POST /api/workflow/start   {"side":"left"|"right"}
POST /api/workflow/advance {"side":"left"|"right","index":1..26}
```

`guided_plan` 和 `guided_state` 只读。`start` 只建立工作流游标，不发运动命令。`advance` 是唯一的逐点目标入口，仍受实体安全门保护。旧的自动整轨 `/api/motion_test/sequence/start` 保持锁定，不应作为日常入口。

## 实验边界

当前完成的是软件工作流和离线验证，不代表真实 Nano、电机、末端或相机已经验证。首次实机只能在确认机械臂无人体接触、急停可用、低速、单步推进和操作者可立即断电的条件下进行；未完成实体授权和反馈核验前不要调用 `advance`。
