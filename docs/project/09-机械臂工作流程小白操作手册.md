# 机械臂工作流程操作手册（仿真版）

本手册给第一次接触项目的人使用。它描述当前控制界面中的“升起—左右转向—小臂伸出—工作走廊—抬升返回”流程。按本手册操作使用仿真地址，不连接真实电机、串口或 D405。

## 1. 确认仿真模式

浏览器打开：

```text
http://192.168.216.129:8081/control
```

页面顶部应看到 `mode: sim`、`system_state: sim_ready` 和 `电机电源：0/5 已上电`。如果地址是 8080、模式是 hardware 或页面显示已连接 Nano，不要按本手册继续。

## 2. 启动仿真服务

服务未运行时，在 zzqVM 终端执行：

```bash
cd ~/PTR/therapy_robot/scripts
./run-host.sh
```

看到 `sim: http://127.0.0.1:8081/sim` 后，用浏览器打开上面的 8081 控制地址。从其他电脑访问时，把 127.0.0.1 换成 192.168.216.129。

## 3. 页面按钮说明

- `左侧 / 右侧`：选择路线方向。
- `开始分阶段流程`：建立新的流程游标，不移动机械臂。
- `回退上一步`：只回退仿真游标，不发送新目标。
- `推进下一步`：在仿真模式推进一个坐标点。
- `仿真路线可用 / 实体执行锁定`：仿真可看，真实执行仍未授权。
- `播放新轨迹仿真（不控制实机）`：一次播放整条路线动画。

## 4. 小白完整操作步骤

### 4.1 选择方向

选择右侧时路线 X 坐标为正，例如 `X=+575 mm`；选择左侧时 X 坐标取反，例如 `X=-575 mm`。两侧的 Y、Z 坐标相同。

### 4.2 开始流程

点击 `开始分阶段流程`，应看到：

```text
分阶段流程：SAFE_HIGH；下一点 1 High ready
```

### 4.3 推进安全高位

点击 `推进下一步`。第 1 点为：

```text
High ready: X=0 mm, Y=232 mm, Z=790 mm
```

这表示末端先升到高于机箱的安全平面。软件会自动通过逆运动学计算 K0-K4，不需要手填关节角。

### 4.4 高位侧向转出

继续点击 `推进下一步`，进入 `SIDE_DEPLOY`。右侧两个点为：

```text
High deploy 1: X=+450 mm, Y=250 mm, Z=790 mm
High deploy 2: X=+575 mm, Y=250 mm, Z=790 mm
```

左侧只把 X 改成负值。规则是先在高位转出，再下降。

### 4.5 小臂伸出并下降

继续推进，进入 `ARM_EXTENDED`。右侧点位为：

```text
Descent 1:     X=+575 mm, Y=250 mm, Z=755 mm
Descent 2:     X=+575 mm, Y=250 mm, Z=720 mm
Descent 3:     X=+575 mm, Y=250 mm, Z=685 mm
Work corridor: X=+575 mm, Y=250 mm, Z=650 mm
```

左侧将 X 改为 `-575 mm`。Z 从 790 mm 分级下降到 650 mm，每一级都做 IK、软限位和碰撞预检。

### 4.6 观察工作走廊

进入 `WORK_CORRIDOR` 后，右侧工作点如下。左侧将 X 全部取反：

| 点 | X(mm) | Y(mm) | Z(mm) |
|---|---:|---:|---:|
| Upper outer | +575 | 300 | 650 |
| Upper inner | +550 | 300 | 650 |
| Upper return | +550 | 250 | 650 |
| Middle inner | +500 | 250 | 650 |
| Middle forward | +500 | 200 | 650 |
| Middle outer | +600 | 200 | 650 |
| Lower forward | +600 | 150 | 650 |
| Lower inner | +500 | 150 | 650 |
| Lower middle | +500 | 100 | 650 |
| Lower outer | +625 | 100 | 650 |
| Lower front | +625 | 50 | 650 |
| Exit inner | +500 | 50 | 650 |
| Exit middle | +500 | 250 | 650 |
| Exit outer | +575 | 250 | 650 |

### 4.7 抬升和回收

继续推进进入 `RETURN_HIGH`：

```text
Lift 1:      X=+575 mm, Y=250 mm, Z=685 mm
Lift 2:      X=+575 mm, Y=250 mm, Z=720 mm
Lift 3:      X=+575 mm, Y=250 mm, Z=755 mm
High exit:   X=+575 mm, Y=250 mm, Z=790 mm
High return: X=0 mm,    Y=232 mm, Z=790 mm
```

必须先在外侧升回 Z=790 mm，再回到中心。最后页面显示 `COMPLETE`。

## 5. 回退上一步

推进到第 N 点后，点击 `回退上一步`，观察下一点编号减 1，再点击 `推进下一步` 重新观察该点。回退不会让模型自动倒退，也不会发送反向目标；第 1 点、未启动流程时按钮自动禁用。切换左右侧后应重新点击开始。

## 6. 播放整条仿真动画

在“三维侧方直线运动测试”中选择左右侧，点击 `播放新轨迹仿真（不控制实机）`。等待页面显示 IK、软限位、小臂投影和碰撞预检通过后观看动画。动画顺序为：

```text
中心高位 → 高位侧向转出 → 外侧分级下降 → Z=650 mm 工作扫描
→ 外侧分级抬升 → 高位回到中心
```

## 7. 坐标和模型数据

坐标系为 `robot_base`：`+X` 是机器人右侧，`-X` 是左侧，`+Y` 是前方/工作扫描方向，`+Z` 是垂直向上。

几何模型参数：

```text
base_height   = 710.0 mm
upper_arm     = 580.0 mm
forearm       = 229.0 mm
wrist_forward = 119.0 mm
forearm_drop  = 80.0 mm
tool_length   = 153.1 mm
```

当前路线默认末端姿态为 `rx=0, ry=0, rz=0`，主要演示位置变化。

## 8. 看到阻塞提示怎么办

`missing_formal_camera_extrinsics` 和 `entity_offsets_unverified` 表示正式实体流程的相机外参、实体轴偏置尚未核验。现在页面已拆分为 `仿真路线可用 / 实体执行锁定`，因此可以继续查看坐标和动画，不要为了消除提示而伪造标定文件。

## 9. 仿真能证明什么

仿真可以证明路线顺序、左右镜像、IK 计算、软限位/碰撞预检、逐点推进和回退逻辑正确；不能证明真实大臂角度、小臂实际长度、Nano 反馈误差、D405 实时识别或人体接触理疗已经验证。实体实验必须另行完成低速、无接触、急停和反馈核验。
