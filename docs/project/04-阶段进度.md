## S3 自动重复定位仿真

- 入口：`build/s3-review-fix/endpoint_repeatability_sim`；用户通过点位 CSV 手动选择一个或多个目标，每点默认 3 次，`--repetitions` 可选择 1 至 100 次。
- CSV 输入支持 UTF-8 BOM、LF/Windows CRLF 和表头/字段首尾普通空白；严格字段数/schema、有限数值、非空且唯一 point_id 校验不变。
- 流程：模拟安全起点 -> 目标 -> 稳定 -> 模拟 K0-K4 反馈 -> FK/误差验收 -> 在目标周围 `BASE_XY` 圆周随机退开 15 mm -> 从局部退开点返回目标；整个实验完成后才返回模拟安全起点。
- 随机 seed 默认 `20260827`，候选最多尝试 36 次；候选的实际反馈位置到退开点、退开点到目标两条路径均复用 IK、正式软限位和 required collision config 预检。
- 报告：逐次 CSV 表和 JSON 状态/统计，真实记录 repetitions、计划/完成样本数、seed、角度、退开 Pose、双向预检和耗时；默认示例 2 点共 6 次，最终 `COMPLETE`。合成反馈不是实体精度结果。
- 故障：移动超时、稳定超时、反馈丢失、不可达/碰撞点均 fail-closed 为 `STOPPED`。
- 回归覆盖默认 3 次、显式 1/5 次、CSV 跨平台输入、同输入/seed/repetitions 字节级复现、不同 seed 改变退开点、15 mm 圆周几何检查和非法参数拒绝。
- 软件边界：`platform=x86_64_vm`、`host=zzqVM`、`nano_tested=false`、`arm64_tested=false`、`entity_hardware_tested=false`、`serial_accessed=false`、`d405_accessed=false`、`shared_memory_written=false`、`motor_target_generated=false`、`motor_command_generated=false`。
