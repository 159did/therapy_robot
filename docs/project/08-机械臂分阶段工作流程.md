# 机械臂分阶段工作流程

本文档是项目关于“升起、左右转向、小臂伸出、工作走廊、抬升返回”的唯一说明，包含实现、接口和仿真操作。当前描述的是软件路线和仿真，不能当成真实 Nano 或人体理疗已经验证。

## 1. 坐标系和拍摄方向

路线使用机器人基座坐标系 `robot_base`：`+X` 是机器人右侧，`-X` 是左侧，`+Y` 是机器人前方也是沿脊椎扫描方向，`+Z` 是垂直向上。因此，顺着脊椎的方向对应 **Y**，不是 X；左右侧由 X 的正负表示。

如果 D405 安装在小臂或腕部，推荐拍摄姿态是：小臂纵向与 Y 平行、相机光轴朝向患者背部，大臂/底座负责把机构转到左侧或右侧。当前路线代码已使用 Y 作为工作扫描方向、X 作为左右镜像方向；但末端目标默认 `rx=0, ry=0, rz=0`，尚未把“光轴朝向背部、小臂始终平行 Y”实现为独立姿态约束，这需要在相机/穴位接入时补齐。

## 2. 流程顺序

```text
SAFE_HIGH → SIDE_DEPLOY → ARM_EXTENDED → WORK_CORRIDOR → RETURN_HIGH
```

先到机箱上方安全高位，再在高位侧向转出；到机箱外侧后才下降；工作完成后先在外侧抬升到高位，再回中心。每个目标都重新进行逆运动学、软限位和碰撞检查，流程不能跳点。

## 4. 小白仿真操作

启动服务：

```bash
cd ~/PTR/therapy_robot/scripts
./run-host.sh
```

打开：

```text
http://192.168.216.129:8081/control
```

确认页面顶部显示 `mode: sim`、`system_state: sim_ready`、`电机电源：0/5 已上电`。然后：

1. 选择左侧或右侧。
2. 点击“开始分阶段流程”。
3. 点击“推进下一步”，观察 `SAFE_HIGH` 的 `High ready`。
4. 继续推进，观察高位转出、外侧分级下降、工作走廊和抬升回中心。
5. 每次只推进一个点，页面显示下一点编号、名称和坐标。
6. 最后一个点完成后显示 `COMPLETE`。

需要重新观察时点击“回退上一步”。它只回退仿真游标，不发送反向目标；随后再次点击“推进下一步”才重新预检该点。第 1 点或未启动流程时按钮自动禁用。也可以在“三维侧方直线运动测试”中点击“播放新轨迹仿真（不控制实机）”一次观看整条动画。

## 5. 接口和安全边界

```text
GET  /api/workflow/guided_plan?side=left|right
GET  /api/workflow/guided_state
POST /api/workflow/start   {"side":"left"|"right"}
POST /api/workflow/advance {"side":"left"|"right","index":1..26}
POST /api/workflow/back    {"side":"left"|"right"}
```

`guided_plan`、`guided_state` 和 `start` 不产生运动命令。`advance` 在仿真模式下推进仿真模型，在实体模式下仍必须经过中央安全门。没有实体授权、有效反馈、正确限位/碰撞和抱闸状态时会拒绝。旧的自动整轨接口继续锁定。

## 6. 模型参数

```text
base_height   = 710.0 mm
upper_arm     = 580.0 mm
forearm       = 229.0 mm
wrist_forward = 119.0 mm
forearm_drop  = 80.0 mm
tool_length   = 153.1 mm
```

末端 Z 不是 K0 的简单复制，而是 K0-K4 和机构几何共同决定。当前默认末端姿态为 `rx=0, ry=0, rz=0`。

## 7. 阻塞提示和完成范围

`missing_formal_camera_extrinsics`、`entity_offsets_unverified` 表示正式实体流程的相机外参和实体轴偏置尚未核验。页面显示“仿真路线可用 / 实体执行锁定”，因此可以继续看坐标和动画，不要伪造标定文件。

已完成：左右镜像路线、安全高位、高位转出、外侧下降、工作走廊、抬升返回、IK、软限位/碰撞预检、仿真逐点推进和回退、控制界面。

未完成：真实 Nano 坐标核验、实际大臂 90° 误差核验、相机姿态约束、D405 实时拍照、穴位坐标转换、压力控制和完整自动理疗。
