# 五轴运动账本说明

记录对象：K0～K4所有由软件接受并实际下发的运动指令。

Nano主记录：

```text
/home/jetsonorin/Documents/therapy_robot/data/motor-motion-history.jsonl
```

Nano同步备份：

```text
/home/jetsonorin/Documents/therapy_robot/data/backup/motor-motion-history.backup.jsonl
```

每行是一个独立JSON事件。事件类型包括：

- `command_start`：该轴位置指令成功发送；
- `progress`：运动期间约每250ms保存一次实际反馈和累计路程；
- `target_reached`：反馈到达目标；
- `stopped`：停止、下电或急停终止运动；
- `superseded`：新目标替换了尚未完成的旧目标。

主要字段：

- `boot_session_id`：Linux启动会话ID，用于Nano时间不准时区分开机批次；
- `time_ms`：本次系统启动后的单调毫秒数；
- `command_seq`：共享内存目标命令序号；
- `axis`：K0～K4；
- `start_native`、`target_native`、`actual_native`；
- `delta_native`：实际反馈相对本次起点的带符号变化；
- `cumulative_abs_native`：运动期间实际经过距离的绝对累计；
- `motor_turns_signed`：`delta_native / 36000`，带方向的电机转子圈数；
- `motor_turns_travel`：`cumulative_abs_native / 36000`，不抵消往返的累计转子圈数；
- `start_display`、`target_display`、`actual_display`、`delta_display`；
- `unit`：K0为mm，K1～K4为deg；
- `elapsed_ms`：该轴本次运动持续时间。

主记录与备份对每个事件同步追加。部署脚本会保留整个`data`目录。日志记录不等同于K1～K4跨断电绝对姿态恢复：K1～K4断电可被手动转动，不能仅凭上次命令位置覆盖本次绝对编码器反馈。
