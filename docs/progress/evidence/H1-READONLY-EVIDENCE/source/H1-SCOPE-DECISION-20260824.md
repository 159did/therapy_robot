# H1 判定范围调整记录（2026-08-24）

## 调整后的正式结论

```text
H1_ENTITY_READONLY_PASS
```

## 新范围

本次 H1 只验证：

- 直接读取真实 Nano 上 K0-K4 的实体反馈；
- 坐标 offset 和 K0 逻辑高度换算；
- online、fault、enabled、velocity 等驱动器反馈；
- 未发送控制命令、未生成目标、未发生运动；
- 未访问 D405；
- 采集器退出和串口释放；
- 原始证据和 SHA-256 完整保存。

## 明确排除项

- 急停按钮没有软件读回接口，本次不把急停串口读回作为 H1 条件；
- 系统不存在硬件看门狗，本次不设置或验证硬件看门狗；
- 控制面板没有启动，也不是直接实体反馈来源；
- K1-K4 没有抱闸，抱闸状态记为 `not_applicable`；
- homed、zeroed、限位和碰撞状态属于运动控制阶段，本次不执行运动，因此不作为只读 PASS 条件。

## 原因

实验目标是验证软件能否在电机保持 disabled、无运动授权的情况下读取五轴实体反馈。把不存在的硬件、未启动的服务或本次明确不执行的运动状态列为阻塞条件，会把只读采样任务错误扩大为完整运动安全认证。

本范围调整不改变原始 `samples.jsonl`、`action-audit.json` 或历史记录；只更新派生报告、README 和判定范围说明。
