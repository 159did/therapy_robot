# H1 轻量只读状态

H1 只做一件事：快速告诉操作者“这台设备是谁，以及五个电机的通信是否正常”。

接口：

GET /api/h1/status

主要字段：

- device_name：设备名称，来自 THERAPY_ROBOT_DEVICE_NAME，未设置时为 therapy_robot。
- run_mode、system_state：当前软件运行状态。
- axes：K0-K4 的 online、fault、enabled、原始位置和换算位置。
- entity_control_authorized：当前是否存在实体控制授权，仅用于显示，不由 H1 设置。

H1 不执行使能、回零、置零、松闸、移动、拍照或标定，也不访问 D405。它不再要求
操作者、急停、看门狗、串口占用、软限位和 SHA-256 等完整审计材料，不再单独阻止
硬件服务启动。实体控制仍由独立的实时反馈、故障、限位、碰撞、抱闸和授权检查决定，
默认状态保持禁止执行。

旧的实体只读采集器和历史证据目录不删除；它们是可选审计材料，不是轻量 H1 接口的
必填输入，也不能单独授予运动权限。
